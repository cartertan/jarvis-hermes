# Jarvis vault template

Copy this folder to ~/JarvisVault, open it in Obsidian ("Open folder as vault"),
then fill in the five notes in Human-Notes/.

- Human-Notes/      written by you; agents read only
- Agent-Memory/     one folder per agent; each agent writes only to its own
- Imported/nexus/   regenerated by the RAG export script; never hand-edit

Keep the vault on local disk and under Git. Do not put it in a syncing cloud folder.
